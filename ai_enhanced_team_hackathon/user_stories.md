# User Stories

1. As a beginner developer, I want to paste a code snippet so that the AI can analyze it.
2. As a beginner developer, I want the AI to explain the bug in simple language so that I understand what went wrong.
3. As a beginner developer, I want the AI to suggest a fixed version of my code so that I can learn the correct solution.
4. As a user, I want to choose the programming language of my snippet so that the analysis is accurate.
5. As a user, I want to see a confidence level for each AI explanation so that I know how much to trust it.
6. As a registered user, I want to save my past reviews so that I can revisit them later.
7. As a user, I want to vote on whether the AI suggestion was helpful so that the system can improve.
8. As a user, I want to copy the fixed code with one click so that I can use it quickly.
9. As an admin, I want to see usage statistics so that I can monitor the service.
10. As a team member, I want clear error messages when the AI fails so that users are not confused.
