### User Story 1
As a passenger, I want to search for nearby drivers so that I can find a quick ride.

**Acceptance Criteria**:
- User enters pickup and destination.
- System displays available drivers within 5 km.
- Ride can be booked in under 2 minutes.

**Priority**: MVP

### User Story 2
As a driver, I want to accept or reject ride requests so that I can manage my schedule.

**Acceptance Criteria**:
- Driver receives a push notification with trip details.
- Driver has 30 seconds to accept or decline.
- Declining a trip does not penalize driver rating.

**Priority**: MVP

### User Story 3
As a passenger, I want to securely pay for rides via app so that I don't need cash.

**Acceptance Criteria**:
- Integration with major credit cards and digital wallets.
- Receipt generated automatically post-trip.
- Payment processed only after trip completion.

**Priority**: MVP

### User Story 4
As a user, I want to rate my experience so that service quality is maintained.

**Acceptance Criteria**:
- Rating prompt appears immediately after trip ends.
- Scale from 1 to 5 stars with optional feedback text.
- Average ratings are visible on user profiles.

**Priority**: High

### User Story 5
As an eco-conscious user, I want to track carbon emissions saved so that I know my environmental impact.

**Acceptance Criteria**:
- Dashboard calculates CO2 saved compared to solo driving.
- Monthly summary stats displayed in profile.
- Milestone badges unlocked for regular carpooling.

**Priority**: Medium

### User Story 6
As a driver, I want to set recurring routes so that I can find matching passengers automatically.

**Acceptance Criteria**:
- Input daily commute time and route coordinates.
- System matches with passengers traveling the same path.
- Notification sent when a match is confirmed.

**Priority**: High

### User Story 7
As a user, I want to recover my account password so that I don't lose access.

**Acceptance Criteria**:
- Email verification link sent upon request.
- Password reset link expires after 15 minutes.
- Successful reset redirects to login page.

**Priority**: Low

### User Story 8
As an admin, I want to view user reports so that I can handle safety issues.

**Acceptance Criteria**:
- Dedicated dashboard for flagged accounts and chats.
- Ability to ban or suspend violating users.
- Log of all resolved reports saved securely.

**Priority**: High
