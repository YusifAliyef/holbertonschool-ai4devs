# Codebase Overview - Legacy CRM

## Age
First release in 2009, last major update in 2015.

## Size
~45,000 LOC in PHP.

## Dependencies
- MySQL 5.6
- PHP 5.4
- Deprecated authentication library
- jQuery 1.x

## Issues
- No automated tests
- Mixed procedural and OOP style
- High coupling between modules
- No documentation for the database schema
- Hard-coded configuration values and credentials
