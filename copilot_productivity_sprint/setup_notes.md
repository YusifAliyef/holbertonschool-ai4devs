# Setup Notes

## Environment & Tool Versions
- **IDE:** Visual Studio Code (Version: 1.95.3)
- **AI Assistant Extensions:** 
  - GitHub Copilot (Version: 1.250.0)
  - Cline / Continue.dev (Version: 3.2.0)

## Setup Steps & Configuration
1. **IDE Installation:** Downloaded and installed VS Code for Linux/Windows from the official website.
2. **Extension Setup:** Installed GitHub Copilot and Cline extensions directly from the VS Code Marketplace.
3. **API Key & Authentication:** Configured secure authentication by signing in via GitHub account and adding a Gemini/Google AI Studio API key into the extension settings.
4. **Verification & Testing:** Tested inline code completions ( to accept) and side-panel chat functionality to ensure proper connection and response generation.
