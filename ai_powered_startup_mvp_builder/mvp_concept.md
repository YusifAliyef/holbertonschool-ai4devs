# MVP Concept - Student Task Planner App

## Problem Statement
Students struggle to organize assignments, deadlines and study time in one place, so they miss deadlines and feel overwhelmed.

## Target Users
- High school and university students
- Self-learners taking online courses
- Student group project teams

## Core Features
- Task creation form (title, subject, deadline, priority)
- Task list with filters by subject and deadline
- Mark tasks as completed with a progress bar
- Deadline reminders shown on the main page
- Export tasks as CSV

## Constraints
- No authentication (data stored in the browser)
- Limited to 100 tasks per user
- Web only, no mobile app in the first version
