# User Stories - Student Task Planner App

## User Story 1
As a student, I want to create a task with a title, subject and deadline so that I can keep track of my assignments.

## User Story 2
As a student, I want to set a priority (low, medium, high) for each task so that I can focus on the most important work first.

## User Story 3
As a student, I want to see all my tasks in one list so that I know what I need to do.

## User Story 4
As a student, I want to filter tasks by subject so that I can study one course at a time.

## User Story 5
As a student, I want to sort tasks by deadline so that I can see which ones are due soon.

## User Story 6
As a student, I want to mark a task as completed so that I can see what is already done.

## User Story 7
As a student, I want to see a progress bar so that I stay motivated.

## User Story 8
As a student, I want to see deadline reminders on the main page so that I do not miss due dates.

## User Story 9
As a student, I want to edit or delete a task so that I can fix mistakes or remove outdated tasks.

## User Story 10
As a student, I want to export my tasks as a CSV file so that I can keep a backup or share them.
